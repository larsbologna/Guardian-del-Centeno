# El Guardián del Centeno

Sitio web de El Guardián del Centeno — panificados artesanales para negocios en Alta Gracia, Córdoba.

**Vista previa (maqueta en revisión):** https://larsbologna.github.io/Guardian-del-Centeno/

> Estado: Etapa 3 — revisión de diseño. Precios, mínimo de compra, zonas y fotos son **de ejemplo** y están marcados así en la página.

## Desarrollo

```bash
npm install
npm run dev      # http://localhost:4321/Guardian-del-Centeno
npm run build    # genera dist/
```

- Datos del negocio y condiciones de envío: `src/config/negocio.ts`
- Categorías, productos e imágenes: `src/data/catalogo.ts`
- Registro de decisiones: `DECISIONES.md`

La rama `gh-pages` contiene el sitio compilado que publica GitHub Pages.
